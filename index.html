Panduan Penggunaan Cepat

  1. Pilih formulir pada Dropdown. PDF akan LANGSUNG TAMPIL di bawah secara instan.
  2. Ketik teks di kolom input (bisa menggunakan tombol Enter untuk baris baru), klik Mode Teks, lalu klik di atas PDF untuk menempelkan teks (Font otomatis tebal).
  3. Klik Mode Ceklis (✓) atau Mode Lingkaran untuk memberi tanda pada pilihan ganda.
  4. Gunakan Mode Edit/Geser untuk memindahkan/memperbesar objek (tarik titik biru di pojok objek).
  5. Gunakan Mode Hapus lalu klik langsung objek yang ingin dihapus.
  6. Klik Download PDF jika sudah selesai.
